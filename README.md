# PC 도우미 (교실 PC 점검·수리)

다정초 정보 AS 밴드에 반복해서 올라오는 고장 중 **설정만 바꾸면 되는 것**을 선생님이 직접 해결하게 돕는 프로그램.
바탕화면 오른쪽 위에 배경처럼 붙어 있다가, 문제가 생기면 눌러서 쓴다.

```
고장 현상 고르기 → 이 PC 상태 점검 → 자동 수리 버튼 또는 확인 순서 안내 → 그래도 안 되면 밴드로
```

밴드로 넘길 때는 반 이름, 증상, 점검 결과, 해 본 것을 글로 만들어 복사해 두고 밴드를 열어 준다.
선생님은 글쓰기에 붙여 넣기만 하면 된다.

## 다루는 증상 (밴드 2025.5~2026.10 글 약 420건 기준으로 고름)

| 갈래 | 증상 | 점검하는 것 | 자동으로 하는 것 |
|---|---|---|---|
| 화면 | 한쪽 화면이 안 나와요 / 내 화면이 학생 화면에 그대로 보여요 / 똑같이 띄우고 싶어요 / 글씨가 커졌어요 / 마우스가 옆 화면으로 안 넘어가요 / 흐려요·글씨 번짐·비율 이상 | 인식한 모니터 수·이름, 복제/확장 상태, 화면마다 지금 해상도와 권장 해상도 | 복제 ↔ 확장 전환, 권장 해상도로 바꾸기(15초 안에 확인 없으면 되돌림) (배율·위치는 설정 창 안내) |
| 터치 | 터치가 안 돼요 / 다른 화면이 눌려요 / 저절로 눌려요·커졌다 작아졌다 / 끄고 싶어요·켜고 싶어요 | 터치 장치 인식·꺼짐 여부, 윈도우 터치 준비 상태 | 터치 화면 맞추기, 터치 끄기/켜기 (둘 다 관리자 확인 창) |
| 소리 | 교실 스피커로 안 나요 / TV에서 안 나요 / 아예 안 나요 / 잡음·삐 소리 / 마이크가 안 나요 / 다른 반 마이크가 들려요 | 출력 장치 목록, 선 빠짐, 지금 쓰는 장치, 볼륨·음소거 | 출력 장치 바꾸기, 음소거 해제 (마이크는 앰프 쪽 안내, 혼선은 정보부장님께 연락 안내) |
| 프린터 | 인쇄가 안 돼요 / 다른 반 프린터로 나가요 / 종이 걸림 / 목록에 없어요 / 스캔이 안 들어와요 | 기본 프린터, 프린터 상태(걸림·용지·토너·오프라인), 쌓인 인쇄, 스캔용 PC 주소·공유 폴더·네트워크 종류 | 기본 프린터 지정, 윈도우 자동 변경 끄기, 쌓인 인쇄 지우기 (스캔은 정보를 붙여 밴드로) |
| 인터넷 | 인터넷이 안 돼요 / 특정 사이트만 안 열려요 | 랜선 연결, IP 주소, 학교 장비 응답, 바깥 인터넷 | 없음 (원인만 좁혀서 안내·밴드) |
| 컴퓨터 | 느려요 / 자꾸 멈춰요 | 마지막 재시작, 메모리 사용, C 드라이브 공간, 메모리 많이 쓰는 프로그램, 임시 파일 | 임시 파일 정리, 다시 시작 (둘 다 먼저 묻고 함) |
| 프로그램 | 엑셀·파워포인트 인증 / 오피스 설치 / 한글 안 열림·인증·설치 | 오피스 종류(학교용 볼륨 / Microsoft 365), 로그인 여부, 한글 설치 여부 | 오피스 365 가입센터 열기 (인증 코드·제품 키·설치 파일 링크는 정보부장님께 묻도록 안내) |

관리자 권한이 필요한 수리는 버튼에 "(관리자 확인 창이 떠요)"라고 적고 윈도우 확인 창을 띄운다. 허락받지 못하면 밴드로 넘긴다.
새 프린터·스캔 연결, 프로그램 설치·인증처럼 업체가 해야 하는 일은 밴드로 넘긴다.

## 설치 (학교 PC, 선생님 계정으로)

1. [최신 릴리즈](https://github.com/uts1002/classroom-pc-helper/releases/latest)에서 설치 파일 하나만 받는다.
   - 다정초: `PcHelper-Setup.cmd` (수리 문의 링크에 다정초 정보 AS 밴드가 들어 있음)
   - 다른 학교: `PcHelper-Setup-General.cmd` (문의 링크가 비어 있어, 처음 문의할 때 주소를 물어봄)
2. 더블클릭한다. ("Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행])
   - 최신 버전을 받아 `%LOCALAPPDATA%\ClassroomPcHelper\app`에 설치하고, 로그인할 때마다 자동으로 켜진다.
   - 바탕화면에 `PC 도우미` 바로가기도 생긴다 (실수로 껐을 때 다시 켜는 용도).
3. 지우려면 윈도우 `설정 > 앱 > 설치된 앱`에서 `PC 도우미`를 찾아 [제거]를 누른다.

한 PC를 여러 계정이 쓰면(돌봄 겸용 교실 등) 계정마다 한 번씩 설치한다.

## 자동 업데이트

- 설치된 PC는 켜고 30초 뒤, 그 뒤로 6시간마다 최신 릴리즈의 `version.txt`를 확인한다.
- 새 버전이면 `app.zip`을 받아 덮어쓰고 스스로 다시 켠다. 도우미 창을 쓰는 중이면 다음 확인으로 미룬다.
- 인터넷이 안 되거나 GitHub가 막혀 있으면 조용히 넘어간다.
- 저장소에서 직접 실행할 때(`src/version.txt`가 `0.0.0-dev`)는 업데이트하지 않는다.

## 새 버전 내보내기 (개발자)

```powershell
.\release.ps1 0.2.0 "터치 갈래 추가"
```

커밋된 상태에서 태그를 올리면 GitHub Actions(`.github/workflows/release.yml`)가 릴리즈를 만든다.
릴리즈 파일: `app.zip`, `version.txt`, `install.ps1`, `PcHelper-Setup.cmd`, `PcHelper-Setup-General.cmd`. 버전 번호는 태그에서 정해진다.

이 저장소에 쓰기 권한이 있는 사람이 모든 설치 PC의 코드를 바꿀 수 있다. GitHub 계정 2단계 인증을 켜 둔다.

## 쓰는 법

- 패널의 [화면]·[터치]·[소리]·[프린터]·[인터넷]·[컴퓨터]·[프로그램]을 누른다.
- 패널의 갈래마다 지금 상태가 한 줄로 보인다 (예: 소리 · 음소거). 주황·빨간 점이면 눌러서 점검한다.
- 패널 제목(PC 도우미)을 끌면 위치를 옮길 수 있다. 위치는 기억한다.
- 패널 오른쪽 위 톱니바퀴를 누르면 설정 창이 열린다: 반 이름, 수리 문의 링크, 학교 안에서 물어볼 사람, 오피스 365 가입센터 주소, 자동 실행. 맨 아래에 제작자 링크.
- 패널을 오른쪽 클릭하면 `작은 아이콘으로 숨기기`, `설정`, `PC 도우미 끄기`, 버전이 있다.
- 작업 표시줄 오른쪽 아래(알림 영역)에도 아이콘이 있다. 왼쪽 클릭은 패널 보이기/숨기기, 오른쪽 클릭은 갈래 바로 열기.
  숨긴 패널은 바탕화면 `PC 도우미` 바로가기를 다시 눌러도 나온다.
- 윈도우를 켜면 자동으로 켜진다 (기본). 알림 영역 아이콘 오른쪽 클릭 → `윈도우 켤 때 자동 실행`으로 끄고 켠다.
- 반 이름은 처음 밴드로 보낼 때 한 번 묻고 `%APPDATA%\ClassroomPcHelper\settings.json`에 저장한다. 설정 창에서 바꾼 값도 여기 저장된다(업데이트로 지워지지 않음).
- **다정초 버전 / 다른 학교 버전**: 수리 문의 링크가 다정초 밴드 그대로면 다정초 버전(`밴드에 올리기`), 비었거나 다른 주소면
  다른 학교 버전(`수리업체에 문의하기`)이다. 다른 학교 버전에서 링크가 비어 있으면 문의 버튼을 누를 때 주소 입력 창이 뜬다.
  점검 안내 문구의 '밴드'도 화면에 띄울 때 '수리업체'로 바꾼다.

## 다른 학교에서 쓰려면

`PcHelper-Setup-General.cmd`로 설치하고, 톱니바퀴 설정 창에서 수리 문의 링크·물어볼 사람·오피스 365 가입센터 주소를 적는다.
(문의 링크는 비워 두면 처음 문의할 때 묻는다.) 업데이트는 이 저장소에서 같이 받는다.

학교 기본값 자체를 바꿔 배포하고 싶으면 저장소를 포크해서 `src/config.json`의 `BandName`, `BandUrl`, `Contact`, `Office365Url`, `UpdateRepo`와
`install.ps1`·`PcHelper-Setup*.cmd`의 저장소 주소를 바꾼다.

## 구조

```
src/PcHelper.ps1     바탕화면 패널 + 도우미 창 + 증상 목록 + 밴드 글 만들기
src/lib/Checks.ps1   증상별 점검(읽기만)과 판단, 수리 버튼 정의
src/lib/Native.ps1   윈도우 기본 기능 호출 (소리 장치, 화면 복제/확장, 바탕화면 고정)
src/lib/Update.ps1   자동 업데이트
src/lib/Status.ps1   패널의 갈래별 '지금 상태' 한 줄 (1분마다 따로 읽기만)
src/fonts/           Pretendard 글꼴 (SIL OFL 1.1, LICENSE.txt 동봉)
src/config.json      기본값: 밴드 주소, 업데이트 저장소, 물어볼 사람 (설정 창 값이 있으면 그것이 먼저)
src/icon.ico         앱 아이콘 (16~64px는 비트맵, 256px는 PNG — 트레이가 PNG 작은 크기를 못 읽음)
src/version.txt      버전 (릴리즈 때 태그로 채워짐)
PcHelper-Setup.cmd   배포용 설치 파일 (최신 릴리즈를 받아 install.ps1 실행) — 다정초용
PcHelper-Setup-General.cmd  다른 학교용 (install.ps1 -General: 문의 링크를 비워 둠)
src/uninstall.ps1    제거 ('설치된 앱' 목록의 [제거]가 실행)
install.ps1 / release.ps1
```

윈도우 11에 기본으로 들어 있는 PowerShell 5.1과 WPF만 쓴다. 따로 설치할 프로그램이 없다.

## 확인 상태 (2026-10-14, 개발 PC)

확인한 것
- 바탕화면 고정: 다른 창 뒤에 깔리고, 바탕화면 보기(Win+D)에도 남는다.
- 점검(읽기): 모니터 2대·확장 상태, 소리 장치 4개(선 빠진 장치 포함), 프린터 목록, 인터넷 단계별 점검.
- 도우미 창: 증상 목록 → 점검 결과 화면.

학교 PC에서 확인할 것 (개발 PC 설정을 바꾸지 않으려고 자동 수리 버튼은 아직 눌러 보지 않음)
- [ ] 화면: 복제 ↔ 확장 버튼이 실제로 바뀌는지 (전자칠판 + 교사 모니터 + 듀얼 3대 구성일 때도)
- [ ] 소리: 출력 장치 바꾸기 버튼, 교실 스피커/TV 구분이 맞는지 (장치 이름이 학교마다 다를 수 있음)
- [ ] 프린터: 기본 프린터 지정, 쌓인 인쇄 지우기
- [ ] 화면: 권장 해상도 버튼과 15초 되돌리기 (번짐 글이 많았던 6학년 듀얼 모니터)
- [ ] 터치: 장치 인식 점검, 터치 화면 맞추기, 터치 끄기/켜기 (관리자 확인 창이 비밀번호 없이 [예]로 넘어가는지)
- [ ] 컴퓨터: 임시 파일 정리, 다시 시작
- [ ] 밴드로 보내기: 글이 복사되고 밴드가 열리는지
- [ ] 내PC지킴이·백신이 실행을 막지 않는지
- [ ] 다시 로그인했을 때 자동으로 켜지는지
